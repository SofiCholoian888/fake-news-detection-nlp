# fake-news-detection-nlp
Классификация русскоязычных научных заголовков на правдоподобные и фейковые
Проект посвящён обнаружению фейковых научных новостей на основе русскоязычных заголовков научных новостей. Реализована классификация без использования трансформеров с применением ансамбля нейронных сетей.

## Описание задачи
Задача бинарной классификации: `0` — правдоподобная новость, `1` — фейковая.

## Данные
*   **Источник**: `combined_dataset (2).csv`
*   **Размер**: 11 723 строки (после очистки — 11 428)
*   **Структура**: `title` (текст заголовка), `is_fake` (метка класса)
*   **Особенности**: Данные сгруппированы по близости заголовков для предотвращения утечки (data leakage).

## Метод
1.  **Предобработка**: lowercase, нормализация `ё→е`, удаление URL/цифр/пунктуации, удаление стоп-слов (с сохранением отрицаний).
2.  **Модели**:
    *   **Baseline**: TF-IDF + Logistic Regression.
    *   **RNN**: BiLSTM (Embedding 128, LSTM 32).
    *   **CNN**: Свёрточная сеть в стиле Kim (2014) с окнами 2/3/4/5.
3.  **Ансамбль**: Взвешенное среднее предсказаний BiLSTM и CNN. Веса подобраны на валидации (`w_BiLSTM=0.25`, `w_CNN=0.75`).

## Результаты на тесте
| Модель | Accuracy | F1-score | ROC-AUC |
| :--- | :--- | :--- | :--- |
| TF-IDF + LR | 0.8402 | 0.8424 | 0.9065 |
| BiLSTM | 0.8229 | 0.8075 | 0.8918 |
| CNN Kim | 0.8438 | 0.8402 | 0.9181 |
| **Ансамбль** | **0.8485** | **0.8440** | **0.9182** |
